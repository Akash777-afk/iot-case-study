# IoT Observability — Case Study

Single-page case study website for the IoT Observability dashboard (TierOne · Airtel IoT NOC), designed and built by Akash Ganapathy.

## Run locally

```bash
npm install
npm run dev      # http://localhost:5500
```

Or double-click `start-localhost.bat`. Opening this folder in VS Code also starts the dev server automatically (VS Code asks once to allow automatic tasks).

## Build

```bash
npm run build    # outputs to dist/
npm run preview
```

## Structure

```
index.html          page markup
src/style.css       design tokens + styles
src/main.js         animations and interactions (GSAP + ScrollTrigger)
public/assets/      dashboard screenshots
```

Research figures, personas and quotes are illustrative placeholders.
